Selenium IDE alternatives for Chrome (2026)

If you open the Chrome Web Store looking for Selenium IDE today, you won't find it. Here is what happened, and the realistic options for keeping your recorded .side tests alive.

What happened to Selenium IDE in Chrome

  • The Selenium IDE Chrome extension was built on Manifest V2, Chrome's older extension platform. It had not been updated since late 2021.
  • Chrome turned off Manifest V2 extensions in July 2025 (Chrome 138), so the extension stopped running.
  • On August 31, 2026 the Chrome Web Store removed the remaining Manifest V2 listings, so it can no longer be installed on a new computer either.
  • The Selenium project's next version, Selenium IDE 4, is a separate desktop app rather than a browser extension. Its last release was a beta in July 2024, and Selenium contributors have said on the selenium-users list that neither the extension nor the app is maintained any more.

Your .side files are still fine — they are plain JSON. You just need something that can run them.

Which one fits you

  • You want to stay with the Selenium project's own tools and don't mind that they are no longer updated: try Selenium IDE 4, or the Firefox add-on.
  • You only need to run existing tests in CI: selenium-side-runner runs .side files from the command line.
  • You also automate desktop apps or need OCR: UI.Vision RPA is a broad RPA tool that can import Selenium IDE projects.
  • You are recording brand-new flows and don't care about .side: Chrome's built-in DevTools Recorder is free and already installed.
  • You want to keep editing and running your .side tests in Chrome, and move them to Playwright when you are ready: that is exactly what SideReplay was built for.
